# Team Vaani Learning Hub

Create a new full-stack web application named Team Vaani, an AI-powered multilingual education platform designed to help students learn in their regional languages while allowing teachers to teach in their preferred language.

TECHNOLOGY:

React

TypeScript

Tailwind CSS

Vite

Supabase for future authentication, database and storage integration.

PROJECT REQUIREMENTS:

Build a responsive web application that works on desktop, tablet and mobile.

Use a clean, modern, accessible educational interface.

Support a future multilingual interface.

Design three separate user roles:

Teacher

Student

Admin

A teacher must eventually be able to assign a student to a particular class.

Students must eventually be associated with their assigned class automatically after login.

Students must not be able to independently change their confirmed class assignment.

Keep the application modular, with reusable components and separate pages.

Prepare the architecture for future integration of speech recognition, machine translation and text-to-speech.

Do not implement fake AI functionality or pretend backend integrations are working.

INITIAL DELIVERABLE:

Create only the basic project foundation:

Application layout

Navigation structure

Landing page

Login and registration page UI

Separate dashboard placeholders for Teacher, Student and Admin

Responsive design

Reusable components

Organized source code

Do not build the complete functionality yet.

Keep the project easy to export, maintain and continue developing through GitHub or another AI coding platform.
